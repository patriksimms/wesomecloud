# WesomeCloud 0.4.3 preview

- The downloaded disk image now shows clear drag-to-install instructions, large app and Applications icons, and an arrow between them. After copying, open WesomeCloud from Applications.

Upgrading from 0.4.1 or earlier rebuilds the Finder location once. Downloaded and unsynced Finder files are preserved outside the replacement location. To find them, in Finder choose Go > Go to Folder and enter `~/Library/Containers/cloud.wesome.wesomecloud/Data/Library/Application Support/WesomeCloud/Preserved Finder Files`. Open the recovery notes there, then use Go > Go to Folder with each recorded path. These notes are readable only by your Mac user and are excluded from diagnostic exports. If a recovery note cannot be saved, the app shows an alert with a copyable path and a Show in Finder action before continuing the rebuild. Check those preserved files for local edits.

Known limitation: automatic remote discovery can stop after the folder traversal limit, tracked in [#23](https://github.com/patriksimms/wesomecloud/issues/23).

Apple Silicon, macOS 15 or later. Existing 0.1.3 or later installations can use Check for Updates.
