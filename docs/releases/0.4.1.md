# WesomeCloud 0.4.1 preview

- Finder updates now resume from a durable SQLite journal after extension restarts.
- Large listings and pending changes are delivered in bounded pages, preventing the oversized-batch extension crash.
- Moves, deletions, download/upload state, and selected-Space changes survive interrupted delivery. Local journal reads remain available without credentials and during metadata writes.

Known limitation: automatic remote discovery can stop after the folder traversal limit. This is tracked in [#23](https://github.com/patriksimms/wesomecloud/issues/23); the delivery fix does not repair traversal continuation.

Apple Silicon, macOS 15 or later. Open the DMG and drag WesomeCloud into Applications. Existing 0.1.3 or later installations can use Check for Updates.
